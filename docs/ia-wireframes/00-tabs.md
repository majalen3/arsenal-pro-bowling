# Wireframe 00: tab bar (5 destinations, no "More")

_All names and numbers are example values for layout only, not data._

```
┌────────────────────────────── 360 ─┐
│ [screen title]              (Me ◯) │  ← Me = profile, handedness, settings, backup (rare, so top-right is fine)
│                                    │
│            … screen …              │
│                                    │
├────────────────────────────────────┤
│ Tonight   Bowl   Results  Bag  Learn│  ← single words, icons + labels, 48 px tall
└────────────────────────────────────┘
```

- **Tonight** = get ready: where, conditions, tonight's bag, start line, who's bowling.
- **Bowl** = only the scoring pad + ball chip + line chip. A "● Game 2 · frame 6" badge appears on the tab only while a game is open (Apple: badges only for critical info).
- **Results** = last night's recap on top, then nights, lines, the Card, and Export.
- **Bag** = My balls (with Status), the Bag builder, compare, insights, care.
- **Learn** = Bowling Guide, Glossary search, Patterns library, "How it works", Help "?" switch.
- Lane / Target stay as full-screen routes opened from the "Stand 17 · Aim 10" chip (Tonight + Bowl) and from Learn › How the lane model works.
